# Solución de Errores Extendida - Adjustment Program

## 1. El programa muestra "Communication Error"
1. Abre el **Administrador de dispositivos** en Windows (`devmgmt.msc`).
2. Despliega la sección **Dispositivos de impresión** o **Controladores de Bus Serie Universal**.
3. Verifica que la impresora no aparezca con un signo de admiración amarillo.
4. Asegúrate de detener cualquier software de escaneo o utilidad de estado de Epson que se esté ejecutando en segundo plano en la barra de tareas.

## 2. El botón "Initialization" no surte efecto
- Confirma que has hecho clic primero en **Check** para que el software registre la lectura inicial.
- Si el proceso falla, ejecuta el programa utilizando la opción de compatibilidad con **Windows 7** o **Windows XP (Service Pack 3)** haciendo clic derecho en `AdjProg.exe` -> *Propiedades* -> *Compatibilidad*.
